## codigo-fuente
Repositorio de código donde se almacenará el trabajo realizado en frontend a lo largo de los sprints para el correcto desarrollo del proyecto.

-------------INICIAR EL PROYECTO-------------

Activar el entorno virtual (en backend):
```
.\venv\Scripts\activate
```

Desactivar el entorno virtual (por si fuera necesario): 
```
deactivate
```

Para activar el backend o frontend, primero meterse en la carpeta de cada uno:
```
cd .\backend\ 
```
```
cd .\frontend\ 
```

Backend: 
```
python server.py
```

Frontend: 
```
npm run dev
 ```
